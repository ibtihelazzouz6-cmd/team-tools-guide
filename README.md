# Team Tools Guide

A shared reference repository for collaborative development tools and workflows.

## Overview
This repository documents essential team collaboration tools, branching practices, and pull request workflows used during development.

## Tools
- **Git & GitHub**: Version control, branches, issues, and pull requests.
- **Documentation (`README.md` & `CONTRIBUTING.md`)**: Shared project documentation and contribution guidelines.

## Workflow
1. Create a branch from `main` for your assigned issue.
2. Make changes and commit them clearly to your branch.
3. Push the branch and open a pull request referencing the issue (`Closes #1` or `Closes #2`).
4. Review changes, address feedback, and merge into `main`.
